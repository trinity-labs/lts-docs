# Capacites

`Scan / Audit` aggregates several signal families to construct a usable view of the exposed surface.

## Signals covered
- DNS and known subdomains
- HTTP and HTTPS exposure
- TLS information
- Security headers
- public redirections and ports of entry
- publicly visible configuration or version indices

## Return
The results are presented in the form of synthesis, technical details and evidence.
Each element must remain traceable to facilitate verification and correction.
