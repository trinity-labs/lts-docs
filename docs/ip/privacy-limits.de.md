# Vertraulichkeit und Beschränkungen

`IP` ist ein Diagnose-Tool.
Es zeigt die Informationen an, die benötigt werden, um zu verstehen, wie eine Verbindung aus dem Internet betrachtet wird.

## Vertraulichkeit
- Der Dienst fordert kein Konto an
- die angezeigten Ergebnisse beziehen sich auf die aktuelle Verbindung
- die Geolokalisierungsdaten näherungsweise
- Browserinformationen können je nach aktiviertem Schutz variieren

## Grenzwerte
GeoIP-, ASN-, Proxy-, VPN- oder Tor-Datenbanken sind nie perfekt.
Ein Ergebnis muss als technischer Index interpretiert werden, nicht als absolute Sicherheit.
