# Data and score

`IP` enriches the observed address with public network or licensed data.
This information is useful for diagnosis, but it remains indicative.

## Data displayed
- ✅ IP address observed
- ✅ ASN and network operator
- ✅ approximate country or geographical area
- ✅ Returns DNS when available
- ✅ browser context
- ✅ VPN, proxy or datacenter indicator

## Score
The score is a read aid signal.
It does not constitute legal evidence and should not be used alone to block a legitimate user.
