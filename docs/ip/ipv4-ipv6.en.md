# IPv4 and IPv6

The service `IP` distinguishes IPv4 and IPv6 with dedicated hosts.
This approach avoids letting the browser choose a single network stack for the entire page.

## Operation
- ✅ the main domain displays the reference address
- ✅ IPv4 probe confirms IPv4 connectivity
- ✅ IPv6 probe confirms IPv6 connectivity

## Reading
If IPv6 does not appear, it may come from the ISP, the LAN, the system, the browser or a VPN policy.
The absence of IPv6 does not necessarily indicate a service failure.
