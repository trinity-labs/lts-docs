# Confidentialite et limites

`IP` est un outil de diagnostic.
Il affiche les informations nécessaires pour comprendre comment une connexion est vue depuis Internet.

## Confidentialite
- le service ne demande pas de compte
- les résultats affichés sont liés à la connexion en cours
- les données de géolocalisation sont approximatives
- les informations navigateur peuvent varier selon les protections activées

## Limites
Les bases GeoIP, ASN, proxy, VPN ou Tor ne sont jamais parfaites.
Un résultat doit être interprété comme un indice technique, pas comme une certitude absolue.
