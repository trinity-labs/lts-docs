# IPv4 und IPv6

Der Dienst `IP` unterscheidet IPv4 und IPv6 mit dedizierten Hosts.
Dieser Ansatz vermeidet, dass der Browser einen einzelnen Netzwerkstapel für die gesamte Seite auswählen kann.

## Betrieb
- ✅ Die Hauptdomäne zeigt die Referenzadresse an
- ✅ IPv4-Sonde bestätigt IPv4-Verbindung
- ✅ IPv6-Sonde bestätigt IPv6-Verbindung

## Lesung
Wenn IPv6 nicht erscheint, kann es vom ISP, dem LAN, dem System, dem Browser oder einer VPN-Richtlinie kommen.
Das Fehlen von IPv6 weist nicht unbedingt auf einen Serviceausfall hin.
