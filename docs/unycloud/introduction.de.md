# Einleitung
`UnyCloud` Der Service beginnt mit einem einfachen Bedürfnis: einen Dateiraum über den Browser verfügbar zu machen, mit einer klaren Benutzeroberfläche, einem konsistenten Branding und einem leichten Betrieb, der so nachhaltig ist, dass er nachhaltig bleibt.

## Was UnyCloud ist
`UnyCloud` ist:

- Eine Cloud-Front für Dateien und Ordner
- Ein Dienst, der unter `<cloud-domain>`
- Eine fortgesetzte Fortsetzung des Filebrowsers, angepasst an die TRINITY-Infrastruktur
- Eine Oberfläche, die von Reverse Proxy, Mounted Storage und Branding Runtime abhängig ist

## Was UnyCloud nicht ist
`UnyCloud` nicht:

- Das kommerzielle Portal `TRINITY`
- Ein Remote Office wie `UnyDesk`
- Eine Bedienkonsole wie `UnyPort`
- Ein komplettes Post-Post-Synchronisationssystem

## Warum diese Dokumentation existiert
Diese Sektion Dokumente `UnyCloud` Die Low-Level-Details Filebrowser bleiben in der Admin-Dokumentation verfügbar, aber der Benutzer muss hier die Rolle des Dienstes, seine Einschränkungen, seinen Zugriffspfad und seine Historie vom Filebrowser bis zum UnyCloud-Fork verstehen können.
