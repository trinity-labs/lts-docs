# Verwendung
`UnyCloud` wird für den Dateiaustausch über den Browser verwendet.

## Anwendungsfälle
- Hinterlegung von Lieferverpflichtungen
- File Recovery Support
- Organisation von Shared Folders
- Schnelles Überprüfen von Inhalten aus einem Browser

## Was zu überprüfen ist
Bevor Sie ein Problem melden:

- Die URL ist gut `<cloud-domain>`
- Die Login-Ergebnisse
- Der erwartete Ordner ist sichtbar
- Datei ist mit dem Upload fertig
- Der Browser zeigt keine alte zwischengespeicherte Version an

## Grenzwerte
`UnyCloud` Es ist nicht als einzige Quelle der Anwendungswahrheit konzipiert, sondern bietet einen praktischen Dateibereich, aber das Workflow-Workout bleibt von `TRINITY` oder durch unterstützende Verfahren.
