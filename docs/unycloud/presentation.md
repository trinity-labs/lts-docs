# Présentation d'UnyCloud
`UnyCloud` est la porte d'entrée web vers les fichiers TRINITY. L'expérience cible est volontairement directe : se connecter, naviguer dans l'espace autorisé, déposer ou récupérer des fichiers, puis partager ou organiser selon les droits disponibles.

## Surfaces visibles
La surface visible repose sur :

- Une page de login brandée
- Une navigation de fichiers
- Des actions de dépôt et téléchargement
- Des opérations de dossier
- Une exposition des assets statiques de branding

## Utilisateurs cibles
`UnyCloud` vise :

- Les utilisateurs qui doivent récupérer ou déposer des fichiers
- Les équipes support qui préparent des livrables
- Les administrateurs qui vérifient l'accès au stockage

## Place dans l'écosystème
`UnyCloud` complète les autres surfaces :

- `TRINITY` porte les comptes, commandes et services
- `UnyCloud` porte les fichiers accessibles en navigateur
- `UnyDesk` porte l'accès distant
- `UnyPort` porte la supervision opérateur
