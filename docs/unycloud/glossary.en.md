# Glossary
## UnyCloud
Product name of the cloud surface of TRINITY files.

## Filebrowser
Application component used as a file browsing runtime.

## Branding
Together `custom.css`, images, logo and favicon that gives Filebrowser the UnyCloud appearance.

## Reverse proxy
Layer `nginx` which exposes the service under HTTPS and route to the internal backend.

## Autofill
A browser mechanism that offers or fills in registered identifiers. On UnyCloud, its behavior depends on SPA rendering and proxy corrections.

## Mounted storage
Arborescence presented to the container as file root.
