# Use
`UnyCloud` is used for file exchange via browser.

## Use cases
- ✅ Deposit of deliverables
- ✅ File Recovery Support
- ✅ Organization of shared folders
- ✅ Quickly checking content from a browser

## What to check
Before reporting a problem:

- ✅ The URL is good `<cloud-domain>`
- ✅ The login results
- ✅ The expected folder is visible
- ✅ File has finished uploading
- ✅ The browser does not display an old cached version

## Limits
`UnyCloud` is not designed as the only source of application truth. It provides a practical file area, but the workflows workout remains carried by `TRINITY` or by supporting procedures.
