# Glossar
## UnyCloud
Produktname der Cloud-Oberfläche von TRINITY-Dateien.

## Filebrowser
Anwendungskomponente, die als Dateibrowser-Runtime verwendet wird.

## Branding
Gemeinsam `custom.css`, Bilder, Logo und Favicon, die Filebrowser das UnyCloud-Erscheinungsbild verleihen.

## Reverse Proxy
Schicht `nginx` die den Dienst unter HTTPS ausstellt und zum internen Backend führt.

## Autoauffüllung
Ein Browsermechanismus, der registrierte Identifikatoren anbietet oder ausfüllt. Auf UnyCloud hängt sein Verhalten von SPA-Rendering und Proxy-Korrekturen ab.

## Befestigte Lagerung
Arboreszenz wird dem Container als Dateiwurzel dargestellt.
